# Overview

## 프로젝트 목표
채팅 UI(Claude 스타일)로 텍스트 프롬프트를 입력하면 ZAI API(CogVideoX-3)를 통해 AI 영상을 생성하고, 생성된 영상을 채팅창 안에서 바로 재생하거나 다운로드할 수 있는 로컬 웹 애플리케이션.

## 기술 스택
- **백엔드**: Python 3.14, Flask
- **프론트엔드**: HTML/CSS/JavaScript (단일 페이지, 프레임워크 없음)
- **영상 생성**: ZAI SDK (zai-sdk 0.2.2), CogVideoX-3 모델
- **배포 환경**: localhost (개인 PC 전용)
- **영상 저장**: `videos/` 디렉토리

## 핵심 기능
1. 채팅창에 프롬프트 입력 → 영상 생성 요청
2. 생성 중 진행 시간 + 진행 바 실시간 표시
3. 완성 시 채팅창 안에 영상 플레이어 + 다운로드 링크 제공

## 비목표 (만들지 않는 것)
- 로그인 / 회원가입
- 영상 생성 히스토리 저장
- 이미지 입력 (텍스트 전용)
- 모바일 최적화
- 외부 서버 배포
