# Chat UI

## 역할
Claude 채팅창 스타일의 단일 페이지 웹 UI. 프롬프트 입력, 생성 진행 표시, 완성 영상 재생/다운로드를 제공.

## 레이아웃
- 화면 중앙 고정 너비 컨테이너 (max-width: 800px)
- 상단: 채팅 메시지 목록 (스크롤 가능)
- 하단 고정: 텍스트 입력창 + 전송 버튼

## 메시지 유형

### 사용자 메시지
- 오른쪽 정렬, 파란 말풍선
- 입력한 프롬프트 텍스트 표시

### 어시스턴트 메시지 — 생성 중
- 왼쪽 정렬, 회색 말풍선
- 진행 바 (0~100%)
- 경과 시간 텍스트 (예: "37초 경과...")
- SSE progress 이벤트마다 실시간 업데이트

### 어시스턴트 메시지 — 완료
- 생성 중 말풍선이 완료 상태로 교체 (새 말풍선 추가 X)
- `<video>` 태그로 인라인 영상 플레이어 (controls, 100% 너비)
- "다운로드" 링크 (`/videos/<filename>`, download 속성)

### 어시스턴트 메시지 — 오류
- 빨간 텍스트로 오류 메시지 표시

## 입력창 동작
- 생성 중에는 입력창과 전송 버튼 비활성화
- 생성 완료/오류 후 다시 활성화
- Enter 키로 전송 (Shift+Enter는 줄바꿈)
- 전송 시 입력창 내용 초기화

## Acceptance Criteria
- [ ] 프롬프트 입력 후 전송 시 사용자 말풍선 즉시 표시
- [ ] 생성 중 진행 바와 경과 시간이 1초마다 업데이트
- [ ] 완료 시 말풍선이 영상 플레이어로 교체
- [ ] 영상 플레이어에서 바로 재생 가능
- [ ] 다운로드 링크 클릭 시 mp4 파일 다운로드
- [ ] 생성 중 입력창 비활성화, 완료 후 재활성화
- [ ] 빈 프롬프트 전송 불가 (버튼/Enter 무시)
- [ ] 새 메시지 추가 시 자동 스크롤 다운
